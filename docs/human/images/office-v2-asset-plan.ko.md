# 사무실 디오라마 에셋 목록 — v2

사무실 파노라마 5장은 공간 구성·가구·소품 배치를 확인하는 참고용입니다. 파노라마 이미지의 신규 생성·재생성이나 이미지 전체를 하나의 3D 모델로 생성하는 작업은 대상에 포함하지 않습니다. 향후 생성 대상은 개별 가구·소품이며, 배치할 때 이 이미지를 참고합니다.

아래 목록은 제공된 제작 계획을 바탕으로 하며, 현재 생성 작업을 실행하라는 지시가 아닙니다.

기준: 벽 없는 단칸 디오라마 5종(A 일반 사무실, B 협업 사무실, C 행정 사무실, D 민원 접수실, E 전문 상담실).
아래는 이미지의 모든 물체를 그대로 복제하는 수량표가 아니라, 3D 제작과 재사용을 위한 에셋 분류다.
공통 에셋은 여러 공간에서 재사용 가능한 기본 모델이며, 모든 공간에 반드시 전부 배치한다는 뜻은 아니다.
색상 변경은 동일 공용 팔레트의 UV 이동으로 처리한다. 아래 색상 명칭은 콘셉트이며 실제 색은 기준 팔레트에서 선정한다. COM 식별자는 계획용이며 정식 AST ID가 아니다.

## 3. 참고 이미지별 가구·소품 배치 목록

- A: 공통 바닥판/표면 + 업무 책상 + 회전의자 + 모니터/입력장치 + 서랍장 + 복합기 + 화분 + 책 + 필기구 + 주황 매트 + A 전용 소품.
- B: 공통 바닥판/표면 + 회전의자 + 노트북 + 화분 + 책 + 필기구 + 머그컵 + 보관 상자 + 컬러 러그 + B 전용 소품.
- C: 공통 바닥판/표면 + 업무 책상 + 회전의자 + 모니터/입력장치 + 서랍장 + 프린터 + 화분 + 서류철/문서 + C 전용 소품.
- D: 공통 바닥판/타일 + 회전의자 + 모니터 + 화분 + 서류철 + D 전용 소품.
- E: 공통 바닥판/목재 + 업무 책상 + 고정형 의자 + 노트북 + 화분 + 책/문서 + 필기구 + 머그컵 + 보관 상자 + 원형 러그 + E 전용 소품.

## 4. 제작 단위와 우선순위

1. 공통 베이스: 바닥판, 책상, 의자, 모니터, 노트북, 서랍장, 화분.
2. 공간 식별용 대형 가구: 협업 테이블/보드, 접수 카운터/대기석, 상담 테이블/책장.
3. 업무 소품: 프린터, 전화, 문서, 도장, 번호표 발급기, 램프.
4. 장식·색상 변형: 책 표지, 러그, 컵, 식물, 가방, 천칭.

책상과 모니터, 의자, 소품은 하나로 합치지 않고 별도 모델로 제작한다.
배치는 공간별 프리팹으로 묶고, 색상만 다른 모델은 공용 재질을 유지하고 팔레트 UV 이동으로 재사용한다.
이미지의 수량·세부 구조는 생성 과정에서 차이가 있으므로 실제 배치 수량은 3D 제작 단계에서 확정한다.
