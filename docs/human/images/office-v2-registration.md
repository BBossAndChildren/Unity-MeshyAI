# 사무실 v2 참고 이미지 등록

사무실 파노라마 5장은 공간 구성·가구·소품 배치를 확인하는 참고용입니다. 파노라마 이미지의 신규 생성·재생성이나 이미지 전체를 하나의 3D 모델로 생성하는 작업은 대상에 포함하지 않습니다. 향후 생성 대상은 개별 가구·소품이며, 배치할 때 이 이미지를 참고합니다.

등록일: 2026-10-31 (Asia/Seoul). 사용자 지정 ZIP의 이미지 5장을 원본 바이트 그대로 등록했습니다.
등록 전 이미지 catalog가 비어 있었으므로 최초 등록 버전은 v001입니다. 파일명의 v2는 시안 이름이며 v001 원본 시안은 이 패키지에 없습니다.

제작 계획의 COM 식별자는 계획용이며 정식 AST ID가 아닙니다. 제공 문서의 제작 지시는 이번 작업에서 실행하지 않았습니다.
모델 원본·Blender 수정본·실제 사용본·Unity 적용본·빌드는 미제공이며 모델 연결(source_images)은 아직 없습니다. 향후 개별 가구·소품 모델이 실제로 이 이미지를 참고한 경우에만 위 PAN ID와 v001을 source_images에 기록합니다.
채색 작업은 수행하지 않았으며 공용 팔레트와 color1/color2 원본은 변경하지 않았습니다.
보존한 이미지 수정 프롬프트는 과거 제작 기록이며 신규 생성 작업 지시가 아닙니다. 출처는 패키지의 image_gen 기록이며 생성 작업 ID·생성일은 미제공입니다. 이미지 사용 권리 조건은 별도 확인이 필요합니다.
Blender/Unity/WebGL 실행 및 성능은 미검증입니다.
