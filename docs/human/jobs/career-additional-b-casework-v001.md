# 추가 직업 체험 B — 157개 교육용 시작 과제

전체 추가 대상의 B 구간 157개 고정 시나리오를 `career-additional-b-content.json`에 작성했습니다. 150개는 직업별 허구 요청·자료·조작 목표·인계 결과를 따로 작성했고, 7개는 기존 `career-next-content.json`의 자료를 그대로 재사용했습니다. 41개 공간의 기존 모델·배치와 공용 재질을 재사용하며 새 모델·유료 생성은 없습니다.

이는 직업별 기본 플레이 시작 과제의 소스 설정입니다. 원래 전체 시나리오의 모든 특수 상황·전문 정답·실행 검수 완료를 뜻하지 않습니다. 임상·법률·금융·전기·기계·위험 행동의 실제 판단은 수행하지 않고, 전문 결정이 필요한 항목은 전문가 확인·미확인 자료 보존으로 구별합니다. 모든 수치·대화·자료는 교육용 허구이며 원본 직업 업무 근거와 분리합니다.

제조·정비는 자료 관찰→모형 조립/눈금 조절/분류→결과 인계, 상담은 질문·응답 확인→조건별 자료 처리→요약 인계, 연구는 요청 기록→구체적 값/표본 처리→결과 검토, 공연은 자료 관찰→장면/동선 구성→교육용 큐 확인, 창작은 의뢰 질문→구성판/치수 편집→시안 검토 등으로 나눴습니다. 실제 작성본에는 31가지 단계 유형 조합이 있습니다. 공통 UI를 사용하되 요청·물품·목표·수치·인계 항목을 직업별로 작성했습니다.

사례에는 의복수선원의 소매58cm 조절, 캐드원의400×300mm 도면 치수, 바이어의50개 납품 요청과 견적 보완, 만화가의 세 장면 콘티, 통역가의 순차 통역 메모, 반도체 기술자의 검사자료 분류, 항공 관제사의 교육용 신고 자료 대조가 포함됩니다. 실제 하드웨어·금융 거래·임상 진단을 실행하거나 전문 자격을 판정하지 않습니다.

모든 항목은 정확히 3개 기존 물건의 nodeName·assetId·assetVersion을 연결하고, 3개 작업면의 명시적 초깃값·목표·허용 오차·선행 조건·명령·오류 보존·초안 유지·초기화 정책을 기록합니다. 실제 bounds·작업면 프레이밍·터치·키보드·직접 드래그·특수 분기는 별도 빌드 실행 검수가 필요합니다. 자료의 출처와 물건 연결 근거는 각 항목의 `original_ref`, `source_basis`, `binding_evidence`로 확인합니다.
