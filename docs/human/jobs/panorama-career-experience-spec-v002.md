# 파노라마 기반 직업체험 구성 명세 v002

파노라마를 기준으로 에셋을 공통 에셋과 비공통 에셋으로 분리하여 명세하고, 해당 공간의 형태·배치·의미에 맞게 3D 장면을 구성한다. 그 장소 안에서 직업별 업무·핵심역량을 반영한 상호작용을 수행한다. 각 미션은 물건 3개와 연결된 업무 흐름을 갖고, 공통 미니게임 10종과 특수 상황 규칙 10종 중 필요한 유형을 조합한다.

규칙·데이터 계약은 [AGENTS.md](../../../AGENTS.md)의 ‘파노라마 기반 직업체험·상호작용 명세’가 단일 기준이다. 이 문서는 전체 초안의 조회와 현재 작성 상태를 설명한다.

## 현재 작성 범위

- 기존 직업 catalog의 552개 직업 전체에 대표 시나리오 초안을 작성했다. 사무보조원 1개를 보존하고 551개를 추가했다.
- [전체 직업별 상세 초안](career-experience-scenarios-v002.md): 원본 업무·역량·공간 선택 근거·물건 3개·행동·성공·오류·특수 분기·에셋 준비 사항.
- [기계용 시나리오](../../machine/catalog/career-experience-scenarios-v002.json): 고정 ID·버전·원본 위치·기본 엔진 연습 데이터.
- [71개 공간의 에셋·직업 역조회](../../machine/catalog/panorama-career-experience-layouts-v002.json): 공통·비공통 후보, 전체 기존 적용 공간, 새 시나리오 적용 후보, 미선택 대안.
- [20종 미니게임 설계](../../machine/catalog/career-minigame-types-v001.json): 이번 확장에서도 같은 설계 ID·버전을 사용했다. 20종 모두 적어도 하나의 시나리오에 설계상 배정됐다.
- [정적 검토 기록](../../machine/evidence/career-experience-scenarios-v002-review.json).

기존 v001은 첫 사무실 사례를 작성하던 시점의 기록으로 보존한다. v001의 ‘551개 작성 대기’는 당시 상태이며 최신 문서는 v002다. 최초 구현용 사무실 프롬프트는 계속 그 사례 하나만 대상으로 한다.

## 작성과 구현의 차이

이번 결과는 71개 장면의 활동 흐름과 직업별 원본 업무를 결합한 기획 초안이다. 기본 엔진 연습 데이터는 라벨·순서·가상 눈금 등 결정적인 테스트용 사례이며, 모든 직업의 전문 문제·정답·장비를 완전히 검증한 최종 문제 세트는 아니다. 구현 전에 직업별 구체 과제와 전문 형상·실물 상태를 검토해야 한다.

선택한 파노라마는 기획상의 대표 장면 제안이다. 원문 장소 분류 밖에서 장면을 제안한 188개 직업은 별도 표시했다. 기존 직업·장소 매핑 원장과 그 승인·검증 상태를 변경하지 않았다. 성직자 1개는 전통을 추정하지 않고 개신교·불교·천주교 세 공간의 대안을 작성했으며 실행할 대안은 미선택이다.

실제 조작 물건으로 선택된 기존 에셋은 재사용 후보일 뿐 동작·콜라이더·분리 부품·Unity 적용을 검증한 결과가 아니다. 범용 모델을 전문 장비로 변형해야 하는 항목, 선택 공간의 기존 에셋 목록 밖으로 제안한 항목도 표시했다. 새 사용처는 실제 배치가 아니라 시나리오 후보 역조회다.

## 다음 구현의 입력

[구현 요청 프롬프트](career-experience-implementation-prompt-v002.md)로 시나리오 ID를 지정한다. 첫 사례는 [사무보조원 상세](office-assistant-experience-v001.md)와 [첫 사례 전용 구현 프롬프트](office-assistant-implementation-prompt-v001.md)를 우선 사용한다.

원본·과거 버전·다른 세션의 Unity 프로젝트를 보존한다. 이번 작성 작업은 모델 생성·Meshy 호출·Unity 편집·빌드·실행을 포함하지 않는다. 기존 게임이나 모델이 다른 세션에서 구현됐는지는 실제 사용 원장과 실행 근거를 별도로 조회한다.
