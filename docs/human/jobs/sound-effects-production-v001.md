## 저장과 검증 범위

원본은 `audio/sound-effects/original/<sound_id>/v001/`, 사용본은 `audio/sound-effects/processed/<sound_id>/v001/exports/`에 분리했다. WAV는 44.1kHz 16비트, MP3는 128kbps다. 현재 생성된 네 개 루프도 WAV를 우선 사용한다. 음원을 모델 AST 목록에 넣거나 실제 Unity 사용·빌드 포함으로 등록하지 않았다.

실제 생성 32회, 중복 유료 재생성 0회. 도구가 보고한 합계는 231크레딧, 2.31 US cents다. 청구서·계정 잔액은 조회하지 않았고 토큰은 미측정이다. 생성되지 않은 76종에 비용을 배분하지 않았다.

원본·WAV·MP3 디코딩, 무음 여부, 사용 WAV 피크와 SHA-256을 검사했다. 주관적 청취, 루프 청취, Unity/WebGL 재생, 모바일 지연·웹 오디오 정책·최종 믹스는 미검증이다. 원본은 수정하지 않고 사용본만 무음·피크·경계를 정리했다.

## 재개 시 처리

서비스가 다음 시도를 허용할 때 `not_started_service_busy` 항목만 같은 node_id로 제출한다. 이미 generation_id가 있는 32종은 다시 생성하지 않는다. 준비된 전체 108종 설정은 specifications.json, 제출 응답은 submissions.json에 보존했다. 작업 공간의 New sfx node 이름은 목록의 node_id로 식별한다. 이 문서는 자동 재시작이나 백그라운드 예약을 등록하지 않는다.

## 사용 후보와 실제 사용

각 생성 음원의 개별 명세와 JSON에 고정 기획 목록의 전체 공간 이름·prompt/panorama/context ID·버전, 모든 연결 직업·시나리오를 기록했다. 같은 소리를 직업별로 중복 생성하지 않는다. 후보 연결은 원래 목록의 객체·행동 키워드 추론을 승계하며 음향 요구사항·실제 배치를 뜻하지 않는다. 미선택 대안의 공간을 확정하지 않는다. 실제 사용 이력은 미등록/미검증이다.
