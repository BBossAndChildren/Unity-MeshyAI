# 전체 공간 공통·전용 에셋 후보 v001

> 이전 작업 스냅샷입니다. 최신 전체 공간·사용처·명세는 [v003](workplace-common-assets-v003.md)을 확인합니다.

파노라마는 최종 배치 확인용 참고도입니다. 실제 제작 단위는 아래 개별 소품이며 동일 후보를 여러 공간에서 재사용하는 것을 우선합니다. 사용자 지시에 따라 종교시설 PRM-064는 나머지 생성 후 다시 작성합니다.

[기계용 후보 목록](../../machine/catalog/workplace-asset-candidates-v001.json) · [현재 모델 목록](../../machine/catalog/assets.json) · [프롬프트](panorama-prompts-v001.md) · [이미지 생성 기록](panorama-generation-v001.md)

총 243개 제작·재사용 후보. 2개 이상 공간에서 쓰는 후보 54개. 기존 모델 참조가 있는 후보 17개. 수량·치수·실제 재사용 가능 여부는 미검증입니다. 이미지와 프롬프트의 소품 수를 실제 제작·배치 수량으로 계산하지 않습니다.

표는 우선 검토 순서이며 기존 모델 확인 → 공통 품목 → 전용 품목 순입니다. 합친 명칭은 모델 계열 후보입니다. 의료·식품용 요구, 높이, 바퀴, 지지 구조가 다르면 별도 형상으로 분리합니다. PC는 본체·모니터·키보드·마우스, 학생 책상·의자 및 도장·인주를 각각 분리했습니다. 책 묶음 재사용은 낱권 분리 가능 여부부터 확인합니다.

모든 후보는 planning_only이며 AST ID 선점·모델 완료·Unity 배치로 등록하지 않았습니다. 기존 모델의 in_progress 상태는 유지합니다. Blender 직접 제작과 공용 팔레트 UV 변형을 우선하며 Meshy 유료 생성은 이 목록 작성으로 실행하지 않습니다. 정확한 원문 표현과 출처는 JSON sources에 보존합니다.
