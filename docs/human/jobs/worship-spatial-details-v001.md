# 교회·성당 공간 특색과 장식 보강 v001

사용자 요청: 공간의 특색·다양성을 살리고 휑한 구성을 보강한다. 좌석이 제대 반대쪽을 보는 오류도 고친다. 여러 소품을 한 Meshy 장면으로 생성한 뒤 Blender에서 분리하여 재사용한다. 공용 소품을 모든 공간에 똑같이 채워 넣는 방식으로 해석하지 않는다.

## 공간별 방향

| 고정 공간 | 공간을 구별하는 구성 | 배색·장식 | 유지할 관계 |
|---|---|---|---|
| 기독교(개신교) 예배실 — 목사 / PRM-064 v002 / PAN-064 v001 | 단순 십자가·설교 강대상·성경, 직선 목재 세로살, 건반과 연주 의자 | 월넛 목재·짙은 청록 좌석과 통로·백합, 간결한 강대상 몰딩과 마이크 | 신도석 → 강대상, 목사의 독서 방향, 중앙 통로 |
| 천주교 성당 — 신부님 / PRM-071 v001 / PAN-071 v001 | 십자고상·미사 제대·독서대·성작·전례서·촛대, 아치와 기하창 | 버건디 좌석과 통로·청색 아치 패널·절제된 금색 테두리·백합 | 신자석 → 제대, 촛대·성작의 지지면, 제대 주변 동선 |

종교의 모든 분파에 대한 건축 규정이 아니라 기존 참고 이미지와 사용자 요청을 바탕으로 만든 두 가상 체험 공간의 미술 방향이다. 단순 십자가와 인체가 포함된 십자고상을 혼용하지 않는다. 기존 직업 초안·미니게임의 정답이나 구현 상태를 이번 장식 작업으로 완료 처리하지 않는다.

## 발견한 오류와 수정 의도

- AST-1247 v001의 좌석 앞 방향은 실제 Seat/Back 형상 기준 로컬 −Y다. 기존 두 공간은 회전 0으로 두어 +Y에 있는 강대상·제대 반대쪽을 바라봤다. 각 4개, 총 8개를 180° 돌린다.
- 책 거치대를 등받이 뒤로 옮겨 좌석 앞을 막지 않게 한다. 쿠션과 찬송가 책을 같은 팔레트로 구성한다.
- 설교자의 독서 위치에 맞춰 강대상 상판과 성경의 기울기·방향을 맞춘다.
- 단상 추가 시 단상 위 모든 물건을 함께 올린다. 성당 십자고상은 기존 독립 지지대도 함께 이동해 공중 부양을 만들지 않는다.
- 초기 Meshy 단순화에서 분리된 작은 파편이 보였다. 해당 시도는 보존하고, 추가 유료 생성 없이 Blender에서 파편과 꽃잎을 보정한다.

## 추가 장식 후보·명세

전체 예산은 최종 GLB를 재열어 반복 수량을 포함해 측정한다. 조립 부모와 구성 에셋은 중복 합산하지 않는다. 팔레트 v001 2508×2508 PNG 한 장과 공용 재질을 유지한다. 원본 색상 칸의 UV만 선택하며 모델별 틴트·새 이미지 무늬를 추가하지 않는다.

## 한 장면 다중 소품 제작

공용 장식 묶음 `DECOR-KIT-001 v001`은 Meshy text-to-3d preview 한 건으로 생성한 보존용 원본 묶음이다. 작업 ID `01a18fda-e5ad-74bc-8d17-aa1aab00c500`, 실제 소비 20크레딧. `meshy/models/original/DECOR-KIT-001/v001/source.glb`와 생성 미리보기를 보존한다. 원본 묶음 경로를 완성된 개별 AST 사용본으로 취급하지 않는다.

생성 결과의 실제 형태는 화분 식물·가지 꽃병·바구니·잎 가지·고리형 조형·피처·얕은 그릇이다. 프롬프트의 3×2 격자와 동일하다고 가정하지 않고, 실제 연결 성분과 경계를 Blender에서 확인해 분리한다. 분리 후 원점은 바닥 접점, 치수는 가상 미터, 앞 방향과 이름은 소품별로 기록한다. 조각으로 나뉜 잎을 별도 완성 에셋으로 잘못 집계하지 않는다.

공간별 사용 후보는 분리 결과를 확인한 뒤 정한다. 성당 제대 주변에 바구니·피처를 무조건 추가하지 않는다. 장식은 독립 배경 물건이며 직업체험의 네 번째 조작 대상이 되지 않는다.

## 실제 상태와 근거

최종 교회·성당 및 좌석 수정은 workplaces-v009에서 검수했다. 공용 분리 소품8개는 미배치·추가 검수 상태다. 파일 생성·정식 등록·장면 배치·빌드 포함·실행·시각 검수는 별도 상태이며 아래 근거에 실제 기록된 범위만 인정한다.

- 조립 원장: [scene-assemblies.json](../../machine/catalog/scene-assemblies.json)
- Unity 사용 원장: [asset-usages.json](../../machine/catalog/asset-usages.json)
- 제작·방향 증거: [worship-enrichment-v001](../../machine/evidence/worship-enrichment-v001/)
- 다중 소품 분리 증거: [shared-decor-v001](../../machine/evidence/shared-decor-v001/)
- 새 빌드 근거: [workplaces-v009](../../machine/evidence/workplaces-v009/)

이번 유료 작업은 꽃꽂이 1건20 + 다중 소품 묶음 1건20 = 실제 40크레딧이다. 길이 제한으로 거절된 프롬프트 1회는 수락된 생성 작업이 아니며 별도 소비로 기록하지 않는다. 유료 refine·remesh·이미지 생성은 사용하지 않았다. 모델별 채팅 입력·캐시·출력 토큰과 금액 배분은 도구에 없어 미측정이며 비용 절감을 실측 수치로 주장하지 않는다.
