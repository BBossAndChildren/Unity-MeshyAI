```text

우선 범위는 사무보조원 career-net-253의 사무실 체험 하나다. 다른 551개 직업은 아직 생성·구현하지 마. 공통 10종·특수 상황 10종은 설계 목록이며 이번에는 명세에 적용된 모듈만 구현해줘.

PAN-001 v001을 배치 참고로 사용하고 기존 AST-020 v003 사무실 조립본과 해당 placements를 먼저 조사해 재사용해줘. 파노라마 이미지를 배경으로만 보여주는 화면이 아니라 실제 3D 사무실에서 물건을 선택하는 체험이어야 한다.

상호작용 물건은 정확히 3개다.
1. 모니터 AST-005 v001: 동료의 출력 요청 확인, 빠진 정보를 질문, 날짜 오류 수정·저장.
2. 복합기 AST-009 v001: 최신 문서를 요청 부수에 맞춰 출력.
3. 뒤쪽 수납장 AST-015 v001: 회의자료 칸에 보관하고 동료에게 처리 결과 인계.

기존 모델의 오브젝트 이름·계층·실제 콜라이더 경계를 확인하고 바인딩해줘. 배경 업무석에 모니터가 둘 있으면 하나만 활성화한다. 문서·동료 대화는 해당 물건에서 여는 UI로 제공해 별도 NPC나 네 번째 3D 조작 물건을 만들지 마.

명세의 가상 문서·요청 데이터, 단계 상태, revision, 정확한 성공 조건, 잘못된 선택 피드백, 재시도·전체 초기화를 구현해줘. EX-008 인계는 기본 경로, EX-007 출력 전 부수 변경은 선택 경로로 실제 구현한다. EX-010 복구 연습은 구현 여부를 명시하고 생략 시 완료 처리하지 마.

MG-008 대화, MG-005 검사, MG-003 순서, MG-001 분류를 재사용 가능한 상태·판정 코드와 시나리오 데이터로 분리해줘. 아직 미구현인 20종 전체를 완료했다고 표시하지 마.

마우스·터치·키보드 대체 조작, 클릭과 카메라 드래그 구별, 단계 잠금, 잘못된 물건 선택 안내, 출력 중 중복 클릭 방지, 일시정지·초기화를 제공한다. 핵심능력은 원문 대인관계능력에 맞춰 요청 확인·정확한 인계로 연결하고 적성 진단 점수를 만들지 마.

Unity 설치·버전·WebGL 모듈과 기존 프로젝트를 먼저 조사하고 사용할 수 있는 환경에서 실행해줘. 편집 프로젝트는 unity/projects/, WebGL 결과는 unity/webgl/builds/에 분리하며 기존 프로젝트·빌드·모델을 덮어쓰지 마. 실행 환경이 없으면 가능한 준비를 끝내고 무엇이 없어 실제 빌드가 안 되는지 명시해줘. 일반 웹 GLB 뷰어 결과를 Unity WebGL 검증으로 대신하지 마.

공용 palette.png 한 장·공용 재질 규칙을 유지한다. 문서 글자는 UI로 표시하고 모델에 새 이미지 텍스처를 넣지 마. 기존 4,308삼각형은 과거 기록이므로 최종 파일·반복 배치·추가 물체를 포함해 재측정하고 전체 5,000 목표를 검토해줘. 조립 부모와 자식 모델을 중복 배치·중복 집계하지 마.

기존 모델과 스크립트 재사용을 우선하고 이번 1건 구현에서 유료 Meshy·이미지 생성 호출은 하지 마. 모델 분리가 꼭 필요하면 기존 원본을 보존해 새 버전으로 만들고 실제 사용 기록에 반영해줘.

완료 전 기본 성공, 날짜 오류, 부수 오류, 분류 오류, 순서 위반, 요청 변경, 출력 중 반복 클릭, 완료 후 재클릭, 초기화를 실제로 실행해 확인한다. Unity·웹 실행 근거, 프로젝트·빌드 경로, 포함 에셋 버전, 수량·삼각형, 미검증 항목을 기록해줘. catalog와 사람용 문서, 실제 사용 이력·builds·전달 문서를 함께 갱신하되 근거 없는 ready·placed·실행 pass를 만들지 마.

한 사례가 실제로 플레이 가능하고 검증되면 실행 방법과 결과를 먼저 보고해줘. 이후 전체 직업 확장은 사용자 검토 뒤 진행한다.
```
