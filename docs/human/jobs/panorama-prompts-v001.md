25개 유효 장소 분류를 69개 단일 공간 구도로 나눴습니다. 기존 A~E 5개는 재사용 대상으로 연결했습니다. 새 이미지 생성은 아직 실행하지 않았습니다. 종교시설 1개는 특정 유형 미정으로 중립 구도 초안이며 선택 후 실행합니다. 장소 추가 확인(0개)은 제외했습니다.

이 자료에서 파노라마는 최종 공간 조립 참고도이며 360도 환경맵이 아닙니다. 각 코드 블록은 공통 스타일을 포함한 완전한 프롬프트이므로 하나씩 복사해 사용합니다. 서로 다른 공간을 한 이미지에 합치지 않습니다. 기존 A~E는 비교용이며 자동 재생성하지 않습니다.

새 결과 이미지를 실제로 받은 뒤 panoramas.json에 미사용 PAN ID와 버전을 부여합니다. PRM은 프롬프트 ID이며 PAN/AST 등록 ID가 아닙니다. 프롬프트의 소품 수와 색상 의도는 실제 모델 수량·삼각형·팔레트 검증 결과가 아닙니다.

색상 팔레트의 정확한 바이트·UV·색상 칸은 모델 제작 단계에서 AGENTS.md대로 적용합니다. 이 이미지 프롬프트로 색상 정확성을 보장하지 않습니다. 이미지 사용 권리는 실제 생성 도구와 결과를 확인한 뒤 기록합니다.

## PRM-001 · 공용 업무 사무실

분류: 사무실·일반 회사·공공기관 / 상태: 기존 참고도 재사용

기존 참고도: PAN-001 v001. 기존 이미지를 우선 사용합니다.

```text
가로 16:9 이미지 한 장. 직업 체험 게임에서 개별 3D 에셋을 조립했을 때의 최종 공간 구도를 보여주는 아이소메트릭 디오라마 참고도를 만든다. 360도·구면 파노라마나 스카이박스가 아니다. 하나의 작은 정사각형 둥근 모서리 두꺼운 베이스 위에 한 장소만 배치한다. 높은 3/4 시점, 전체 베이스가 잘리지 않고 사방 여백이 보이게 한다. 벽·천장·문·창문 없이 개방된 구도, 따뜻한 크림색 단색 배경, 부드러운 조명. 귀엽고 단순한 로우폴리 형태, 두꺼운 가구 실루엣, 넓은 평면 색상, 주요 가구·설비 5~8개 중심으로 작은 소품은 절제한다. 인물·동물·로고·워터마크·읽을 수 있는 글자·사진 질감·복잡한 나뭇결·강한 반사·콜라주·여러 방을 넣지 않는다. 각 물체가 서로 합쳐지지 않게 명확한 간격을 둔다. 설비 자체의 구조물·짧은 안전 난간은 필요할 때만 허용한다. 파스텔 기본색과 작은 대비색으로 구분하되, 이 이미지를 실제 재질 텍스처로 사용하지 않는다.

공간: 공용 업무 사무실.
의미: 직원들이 각자 PC 업무를 하며 공용 기기를 공유하는 회사.
핵심 가구·소품: 주황 회전의자, 개인 책상, 모니터, 키보드, 낮은 스크린, 복합기, 낮은 수납장.
배치: 업무석을 중앙에 묶고 복합기와 수납장을 주변에 둔다.
이 공간의 역할이 색상뿐 아니라 가구 관계와 작업 흐름으로 즉시 읽히게 한다.
```
