# WebGL 빌드 목록

현재 등록된 빌드는 없습니다.

[전체 빌드 데이터](../../machine/catalog/builds.json)에서 build_id로 조회합니다.

| 필드 | 내용 |
|---|---|
| project_path | Unity 프로젝트 |
| output_path | 로컬 WebGL 실행 파일 폴더 |
| document_path | 목적·Unity 버전·소스 커밋·날짜를 설명하는 문서 |
| artifact_url | 전달 또는 실행 URL; 업로드 전에는 null |
| assets | 포함된 에셋 ID와 고정 버전 |

빌드별 설명은 이 폴더의 `<build_id>.md`에 작성합니다.
