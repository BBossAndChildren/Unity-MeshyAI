# office-ten-v002 — 사무실 테마 신규 직업체험10종

후보 빌드: 실제 전체 업무 검수 진행 중. 이전 빌드의 통과를 승계하지 않는다.

Unity 6000.3.26f1 실제 빌드 성공, 오류0·경고0, 55915653 bytes. 동일 Unity 프로젝트의 새 OfficeTen.unity에서 기존 AST-020 v006을 재사용한다.

실제 물리 배치는17개 구성 에셋 버전·30인스턴스·4308삼각형이다. 10개 업무 프로필이 공유하므로300배치로 집계하지 않는다. 모델 재질1개·PNG1장(2508×2508), 조작 물건3개. 새로운 모델·유료 호출은 없고 기존 소품17개와 조립1개를 재사용했다.

실제 native Play Mode10종 선택/형상/연결 검수는 통과했다. 네이티브 업무 GUI는 미검증이며 직접 작업 화면·과정 원장은 HTTP WebGL 검수로 구분한다.
