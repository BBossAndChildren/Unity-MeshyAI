## 생성 프롬프트

One very quiet short digital tick, subtle text-field edit feedback, not a keyboard. One isolated cue, clean short natural decay, silence after. Friendly low-intensity educational game sound. No speech, no music, no unrelated sound.

## 처리와 검사

원본 바이트를 보존했다. 사용본은 앞뒤 무음 정리, 단발 시작·끝의 3ms 페이드 또는 루프 20ms 경계 크로스페이드, 역할별 샘플 피크 조절을 적용했다. 원본·WAV·MP3를 실제 디코딩했고 사용 WAV의 무음 여부와 샘플 피크를 검사했다. 원래 계획 길이와 생성된 길이가 다를 수 있어 실측값을 별도로 기록했다. MP3의 엔코더 패딩·브라우저 루프는 실행 검수가 필요하며 정밀 루프에는 WAV를 우선한다.
