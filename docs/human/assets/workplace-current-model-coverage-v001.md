# 현재 최종 모델 증거 범위

현재 참조 319개 전부에 대해 개별 최종 GLB 재수입, 정면·측면·후면, 축소 시트를 확보하고 실제 검토했다. 원본 GLB 해시는 렌더 당시 증거와 모두 일치한다. 모델·참조는 변경하지 않았다.

| 범위 | 현재 개수 |
|---|---:|
| 새로 제작한 소품 | 231 |
| 재사용 공통 소품 | 17 |
| 소품·공통 구성요소 합계 | 248 |
| 조립 공간 | 71 |
| 현재 최종 모델 참조 합계 | 319 |
| 현재 방향별 이미지 | 957 |
| 현재 전용 축소 시트 | 30 |
| 실제 공간 배치 인스턴스 | 805 |
| 명시적 바닥·지지 검토 대상 | 476 |

이전 466은 현재 모델 개수가 아니라 보존 버전을 포함한 당시 렌더 수다. 재사용 17개 모델의 개별 증거를 보완한 후 누적 렌더는 483버전이며, 이 중 현재 319개와 비현재 보존 164버전을 구분한다. 현재 개별 증거가 없던 재사용 17개를 조립 문맥의 검토만으로 완료라고 간주하지 않고 실제 Blender로 별도 재수입·렌더했다.

[현재 모델별 정확한 GLB 해시·방향 이미지·축소 시트 위치](../../machine/evidence/workplaces-model-review-v001/current-final-319/coverage.json). 805개 배치는 전체 공간 인스턴스 수이며, 476개는 지지 검토 대상의 부분집합이다.

검토는 주요 외형·눈에 보이는 누락·지지와 축소 가시성 범위다. 기존 공통 17개는 합쳐진 메시이므로 내부 부품을 개별 분리 측정했다고 주장하지 않는다. 세밀한 색 번짐·밉맵·전문 장비의 정확성과 실제 브라우저 검수는 별도 범위다. Room42 CND-161의 10mm 바닥 교정 대상은 깔짚 패드이며, 이전 제작 이유에 울타리 기둥이라고 적힌 것은 명칭 오류다. 실제 모델·배치는 바뀌지 않는다.
