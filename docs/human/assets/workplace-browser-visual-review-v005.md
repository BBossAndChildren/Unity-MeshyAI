# WebGL v005 실제 화면 시각 검토

실제 HTTP 브라우저에서 캡처한 71개 공간의 1440×900·900×600 이미지 142장을 모두 확인했다. 주요 모델 누락, 자홍색 대체 재질, 공간의 화면 밖 잘림, 주요 지지물 소실은 발견하지 못했다. 실제 캡처를 조합한 [12개 공간 개요](../../machine/evidence/workplaces-v005/visual-review/actual-http-12-room-overview.jpg)와 [공간별 시각 검토 원장](../../machine/evidence/workplaces-v005/visual-review/screenshot-review.json)을 보존한다.

선택 캡션에 COM ID·Blender 제작 방식이 노출되는 작은 UI 문제가 보였다. 별도 기능 검사에서 v005의 900×600 Tab 좌표와 전환 시간 문제가 보고되어 v006이 제작된다. 이 문서는 v005의 화면 표시 범위에 대한 결과이며 전체 기능 통과나 최종 전달 빌드의 승인으로 사용하지 않는다. v006은 새 실제 화면으로 따로 검토한다.

모든 작은 부품의 차폐, 임의 회전·확대, 세밀한 텍스처 필터와 성능은 이 두 화면으로 전부 판단하지 않는다. Blender 모델 319개·배치 805개·지지 대상 476개의 증거와 브라우저 캡처 결과를 구분한다.
