# 에셋 분류·색상 변형·사용 이력 안내

상세 규칙의 단일 기준은 [AGENTS.md](../../../AGENTS.md)의 데이터 계약입니다. 이 안내는 조회 순서와 기록 구분을 설명합니다. 신규 변형·사용 이력 목록은 아직 계약만 정의하며 실제 등록 작업에서 생성합니다.

## 자료를 따라가는 순서

직업 ID → 공간의 occupation_groups → context_id·버전 → panorama_ref → asset_slots.asset_ref → 개별 에셋 → 색상 변형 → 실제 사용 이력.

- 기준 파노라마는 최종 공간의 형태·배치·의미 참고입니다. 새 이미지 생성이나 360도 배경 사용 지시가 아닙니다.
- source_images는 에셋 제작에 직접 참고한 이미지입니다. 공간의 파노라마를 자동 복사하지 않습니다.
- 여러 직업이 같은 공간을, 여러 공간이 같은 에셋을 공유할 수 있습니다. 동일 에셋 버전의 여러 Unity 프로젝트 등록은 여전히 지원하지 않습니다.
- 직업 후보의 추정 근거·적용 조건·사실 검증과 사용자 기획 승인은 서로 다릅니다.

## 재사용할 에셋 찾기

| 분류 | 예시 | 의미 |
|---|---|---|
| object_type | 책상 | 물체 종류 |
| function | 작업면제공 | 기능·용도 |
| space | 사무실 | 적용 가능한 공간 유형 |
| activity | 문서작성 | 지원하는 활동 |

위 값은 표기 예시입니다. 정규 어휘·별칭은 AGENTS.md에서 관리하고 기존 공간 태그도 확인합니다. '데스크'를 별도 태그로 늘리지 않고 '책상'으로 검색·등록합니다.
특정 공간의 적용 후보는 applicable_contexts로 연결합니다. 태그나 후보 연결만으로 실제 사용됐다고 판단하지 않습니다.

## 같은 형상의 색상 변경

- 기존 모델을 재사용하고 공용 팔레트 UV를 다른 칸으로 옮기는 방법을 우선합니다.
- 변형 레시피는 기준 에셋 ID·버전, variant_id, 부위, 팔레트 버전과 원본 색상 칸의 행·열을 연결합니다. UV 좌표를 별도로 복사하지 않습니다.
- 기본 면은 color1 출처, 강조는 color2 출처이며 공용 PNG 한 장·공용 재질 규칙을 유지합니다.
- 계획은 planned이고 결과 에셋은 없습니다. 실제 UV·GLB 파일이 바뀌면 같은 에셋 ID의 새 버전으로 저장한 뒤 materialized 변형과 연결합니다.
- materialized는 결과 파일이 있다는 뜻이며 검수 완료를 자동 의미하지 않습니다.

## 어디에 사용됐는지 확인하기

사용 이력의 단일 기준은 향후 등록할 `docs/machine/catalog/asset-usages.json`입니다. 에셋별 사용처는 여기서 조회합니다. 아직 파일이나 항목이 없으면 사용 이력이 미등록된 것이며 '사용되지 않음'으로 단정하지 않습니다.

| 구분 | 기록 의미 | 실제 장면 수량에 합산 |
|---|---|---|
| 사용 예정 | 계획 경로·예상 수량 | 아니요 |
| 프리팹 정의 | 재사용할 구성 정의 | 아니요 |
| 실제 장면 배치 | 확인한 인스턴스·수량 | 예 |
| 빌드 포함 | 특정 배치 revision의 포함 스냅샷 | 해당 빌드 기준으로 별도 조회 |
| 실행 검증 | 특정 revision·환경의 실행 결과 | 수량을 추가하지 않음 |

정의된 프리팹 하나를 장면에 네 번 배치했으면 수량은 4입니다. 부모 조립 모델과 그 자식 모델을 동시에 합산하지 않습니다.
현재 사용처는 usage_id별 최신 revision을 보고, 과거 배치·빌드 기록은 이력으로 보존합니다. 수량과 삼각형을 모든 revision에 걸쳐 더하지 않습니다.
배치 확인, 빌드 포함, 실행 통과는 각각 별도 근거가 필요합니다. GLB 뷰어 실행을 Unity WebGL 검증으로 대신하지 않습니다.

## 기존 자료에 미치는 영향

schema_version: 3을 유지하는 선택적 확장입니다. 기존 항목은 즉시 마이그레이션하지 않고 실제 관련 작업에서 확인된 정보를 추가합니다. 필드 누락은 미확인, 빈 배열은 해당 기록 범위에서 확인된 항목 없음, null은 계약에서 허용한 미정·해당 없음입니다.
이번 지침 갱신은 모델·이미지·팔레트·장면 제작, catalog 등록, 승인·검수 상태 변경을 포함하지 않습니다.
