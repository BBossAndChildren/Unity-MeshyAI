# 물건 확대·직접 작업형 직업체험 안내

필수 동작·명세 필드·검수 조건의 단일 기준은 [AGENTS.md의 물건 확대·직접 작업형 직업체험](../../../AGENTS.md#물건-확대직접-작업형-직업체험--필수-동작과-명세-계약)이다. 이 문서는 자료를 읽고 적용하는 순서를 안내한다.

## 적용 순서

1. 기존 시나리오 패키지의 ID·버전·작성 상태와 실제 구현·사용 이력을 조사한다. 직업 목록에 있는 항목과 작성된 시나리오를 구별한다.
2. [office-assistant-v005](../builds/office-assistant-v005.md)와 Unity 소스·데이터·실행 근거를 확인한다. 확대·팝업의 참고 구현과 새 요구에서 보완할 조작을 구별한다.
3. 실제 3D 물건과 작업 면을 정하고 `interaction_flow`, 각 물건의 `closeup`, 각 단계의 `work_surface`를 작성한다. 내부 필수 필드와 적용 시점은 AGENTS.md를 따른다.
4. 직업의 원본 업무·역량에 맞는 작업 자료와 직접 조작을 정한다. 같은 버튼 퀴즈로 치환하지 않고 문서 편집·용지 설정·분류함 이동처럼 물건의 역할을 표현한다.
5. 기존 작성 시나리오의 수정 설계와 대표 사례를 먼저 검토한다. 신규 직업의 대량 생성·구현은 명시적으로 요청된 범위에서 진행한다.
6. 구현 시 판정·상태, 데이터, 화면 표현을 분리하고 실제 Unity·WebGL에서 검수한다. 그때 실제 바뀐 사용 이력·빌드·전달 문서를 갱신한다.

## 현재 문서 변경의 의미

이 안내와 지침 추가는 시나리오·모델·게임·빌드가 갱신됐다는 뜻이 아니다. 기존 명세에 새 필드가 없으면 아직 이 방식으로 구체화하지 않은 상태다. 기존 catalog의 승인·구현·실행 상태를 일괄 승격하지 않는다.

대표 사례의 선택지 버튼 등 기존 동작이 새 요구를 모두 충족하는지도 별도로 확인한다. 지침에 적힌 기능, 소스에서 확인한 기능, 기존 실행 기록, 이번에 실제 실행한 결과를 구별해 보고한다.
